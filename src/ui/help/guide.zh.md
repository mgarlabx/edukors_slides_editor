# 教师指南 — Edukors Slides Editor

本指南介绍如何在 Edukors Slides Editor 中制作演示文稿，从第一张幻灯片到可以放映的文件。您不需要编写 HTML：一切都在幻灯片上直接完成，也可以借助 AI 助手。

## 1. 一句话说明

演示文稿是一组**幻灯片**，每张都是一个小网页，共享同一外观：**基础**（颜色、字体以及位于所有幻灯片背后的内容）和**版式**（内容的排列方式）。编辑器把一切保存在一个 `.eslx` 文件中，并导出为**一个 HTML 文件**，在任何浏览器中都能打开，离线也可以。

## 2. 安装和打开

**Mac**（Apple 芯片或 Intel，macOS 13 或更高版本）：

1. 下载 [`Edukors-Slides-Editor-mac.dmg`](https://github.com/mgarlabx/edukors_slides_editor/releases/latest/download/Edukors-Slides-Editor-mac.dmg)，打开后把应用拖到**应用程序**文件夹。
2. 打开应用。第一次打开时，macOS 会询问是否打开从互联网下载的应用：点击**打开**。

**Windows**（10 或 11，64 位）：

1. 在 Microsoft Store 中打开编辑器页面 [Edukors Slides Editor](https://apps.microsoft.com/detail/9PHLLNHZW4Z2)，点击**获取**。不会出现警告，也不需要管理员密码。
2. 编辑器位于“开始”菜单中。新版本通过 Microsoft Store 更新，与其他从商店安装的应用一样。

没有 Microsoft Store 时（有些学校电脑会关闭它），请使用安装程序 [`Edukors-Slides-Editor-windows.exe`](https://github.com/mgarlabx/edukors_slides_editor/releases/latest/download/Edukors-Slides-Editor-windows.exe)。如果浏览器不信任该文件，请选择**保留**；如果 Windows 显示 **Windows 已保护你的电脑**，请点击**更多信息**，再点击**仍要运行**。

**Linux**（64 位，x64）：

- 在 **Ubuntu、Debian、Mint** 及其衍生版上，下载 [`Edukors-Slides-Editor-linux.deb`](https://github.com/mgarlabx/edukors_slides_editor/releases/latest/download/Edukors-Slides-Editor-linux.deb)，双击安装（或 `sudo apt install ./Edukors-Slides-Editor-linux.deb`）。编辑器会出现在应用菜单中，双击 `.eslx` 即可用它打开。
- 在**其他发行版**上，下载 [`Edukors-Slides-Editor-linux.AppImage`](https://github.com/mgarlabx/edukors_slides_editor/releases/latest/download/Edukors-Slides-Editor-linux.AppImage)，设为可执行（`chmod +x`）后打开。无需安装即可运行。

有新版本时，编辑器会提示并提供下载页面（通过 Microsoft Store 安装时，更新由商店提供）。

**在所有系统上**，第一次打开时编辑器会显示**使用条款**（附说明的 MIT 许可证）：必须接受后才能继续。之后可在**帮助**中查看，帮助中还显示编辑器的版本。然后您可以**新建演示文稿**或**打开** `.eslx` 文件。安装后，双击 `.eslx` 即可在编辑器中打开。

**旧版本文件和 PowerPoint 文件。** **打开**也接受 `.esf`（编辑器旧版本）和 `.pptx`（PowerPoint）演示文稿。它们会转换后在一个没有文件的标签页中打开：原文件绝不会被修改，**保存**时会要求输入名称并写入一个新的 `.eslx`。PowerPoint 转换会带入文本、图片和简单形状；无法转换的内容会列在幻灯片上方的提示中，并随演示文稿一起保存。

## 3. 窗口

| 部分 | 作用 |
| --- | --- |
| **顶部栏** | 文件（新建、打开、最近、保存、导出、在文件夹中显示）、**放映**以及**幻灯片**与**幻灯片母版**之间的切换、撤销和重做、编辑（剪切、复制、粘贴、复制副本、删除）、**插入**（文本、形状、图片、链接、互动问题）、设置和帮助。右侧是幻灯片列表（⌥⌘0）和 **AI 助手**（⇧⌘A）。 |
| **标签页**（下方） | 每个打开的演示文稿一个标签页。标签上的圆点表示有未保存的更改；**+** 新建另一个演示文稿。 |
| **格式栏** | 所选对象的字体、字号、颜色、粗体、斜体、下划线、线条、填充、阴影和裁剪。 |
| **幻灯片列表**（左侧） | 缩略图，以及用于新建、移动、复制副本、复制、剪切、粘贴和删除幻灯片的工具栏。 |
| **幻灯片**（中间） | 正在编辑的幻灯片；下方是**演讲者备注**。 |
| **AI 助手**（右侧） | 与创建和修改幻灯片的助手的对话。 |
| **状态栏** | 是否已保存、幻灯片编号及其**版式**（点击可更改），以及编辑器版本。 |

主题（浅色、深色或跟随系统）、界面文字大小和语言位于**设置 → 应用程序**。

幻灯片列表和 AI 助手可以调整宽度：拖动面板的内侧边缘（或在其获得焦点时使用方向键）；双击边缘可恢复默认宽度。

## 4. 逐步创建演示文稿

1. **新建演示文稿。** 点击新建演示文稿图标（或按 ⌘N），选择模板：*空白演示文稿*或您的某个模板。双击或点击**创建**即可打开。
2. **添加幻灯片。** 幻灯片列表顶部的新建幻灯片按钮（或 ⇧⌘N）会显示所有版式：双击或点击**插入**选择一个。
3. **输入内容。** 点击幻灯片上的文本即可直接编辑。
4. **请助手帮忙。** 打开助手（⇧⌘A），描述您的需求：“为六年级制作三张关于水循环的幻灯片”。见第 7 节。
5. 用 ⌘S **保存**。第一次保存时，编辑器会询问保存位置和名称：整个演示文稿就是一个文件 `my-lesson.eslx`，可以随意复制、移动和重命名。

文件只保存演示文稿实际用到的内容（没有被任何幻灯片引用的图片和字体会在保存时去掉），因此体积较小。有未保存的更改时，编辑器会保留草稿：如果意外关闭，下次启动时会提供**恢复**。如果文件在编辑器外被修改（其他程序、同步），覆盖前会先询问。

要重复使用某种外观，请在演示文稿打开时打开**新建演示文稿**图库，使用**另存为模板**：模板会出现在图库中，也可以在那里重命名和删除。

## 5. 在幻灯片上编辑

幻灯片的操作方式与 PowerPoint 或 Google 幻灯片相同：

- **选择。** 点击对象（文本、图片、形状、链接）即可选中；⇧ 或 ⌘ + 点击可加选；从空白处拖动可选中矩形内的所有对象。⌘A 选中幻灯片上的所有对象。Tab 依次切换对象。
- **移动。** 拖动对象（文本需拖动其边框）。粉色参考线显示与边缘和中心的对齐；按住 ⌥ 可关闭吸附，按住 ⇧ 只沿一个方向移动。方向键每次移动 1 像素（⇧ 时 10 像素）。
- **调整大小。** 拖动白色控制点；图片会保持比例（⇧ 可取消）。⌘ + 方向键也可调整大小。选中多个对象时，拖动组轮廓上的控制点可同时调整所有对象的大小。
- **文本。** 在文本内点击即可编辑，并保留格式。选中一段文字后，可在格式栏中更改字体、字号或颜色。
- **图片。** **插入 → 图片**会粘贴已复制的图片；如果没有，则会要求选择文件。也可以把电脑上的图片拖到幻灯片上。如果版式中有空的图片位置，图片会放到那里。裁剪按钮会打开带控制点的裁剪框：Enter 确认，Esc 取消。
- **形状和链接。** 所选形状会放到幻灯片上，线条和填充可调。链接使用已复制的地址；说明文字会替代地址显示在幻灯片上，**二维码**选项会在旁边放上二维码。
- **层次和对齐。** 右键点击对象可选择**置于顶层**、**置于底层**，文本还可设置水平和垂直对齐。
- **在幻灯片和演示文稿之间复制。** 复制的对象（⌘C）可以粘贴（⌘V）到另一张幻灯片，甚至另一个演示文稿中，外观和动画保持不变。

每个操作都是一步撤销（⌘Z）。只有 Esc 能取消正在进行的操作。

**列表中的幻灯片。** 点击缩略图即可跳到该幻灯片；⇧ 和 ⌘ 可多选。列表获得焦点时，⌫ 删除所选幻灯片，⌘D 复制副本，⌘C/⌘V 复制粘贴（也可粘贴到另一个演示文稿，并采用其外观）。⌘↑ 和 ⌘↓ 调整顺序；Home 和 End 跳到第一张和最后一张。以最后点击的区域为准：点击幻灯片后，⌫ 和 ⌘D 作用于对象，而不是幻灯片。

## 6. 幻灯片母版：基础和版式

顶部栏中“放映”旁边的**幻灯片母版**会把幻灯片列表换成两个标签：

- **基础。** 每个基础是整个演示文稿的一种备选外观：颜色、字体以及位于所有幻灯片背后的对象（标志、色带）。在面板中选中的基础即为**当前**基础（缩略图下方标有 ✓），它作用于所有幻灯片。这样您可以在不改动内容的情况下尝试另一种外观。
- **版式。** 每个版式是一种内容排列（封面、标题和正文、两栏……），由所有基础共用。新幻灯片从某个版式开始。来自版式的内容只能在这里修改，修改会应用到所有使用它的幻灯片；在幻灯片上，只能编辑版式占位区中的文本和图片。

双击名称即可重命名。演示文稿始终至少保留一个基础和一个版式；被删除版式的幻灯片会连同内容转到前一个版式。要**更改幻灯片的版式**，请点击状态栏中的版式名称：文本会进入新版式中同名的字段。

代码细节（基础和版式的 HTML 与 CSS）交给助手：可以说“把所有幻灯片的标题改成藏青色”或“创建一个左图右文的版式”。

## 7. AI 助手

顶部栏最右侧的助手按钮（或 ⇧⌘A）可在幻灯片旁打开或关闭**助手**；关闭不会中断或清除对话。助手能看到演示文稿，并按您的要求修改：创建和改写幻灯片、更改外观、从网上获取图片。它只处理该对话所属的演示文稿，在编辑器自己的文件夹中工作（而不是您文件所在的文件夹），并且从不删除幻灯片：这由您决定。

**使用前。** 在电脑上安装 [Claude Code](https://claude.com/claude-code) 或 [Codex](https://developers.openai.com/codex/cli/)；编辑器不会自动下载。然后在**设置 → AI 助手**中添加账户，并通过浏览器登录。账户属于您，不属于编辑器，并可用于这台电脑上的其他 Edukors 应用。

**如何提问。** 在下方输入框中输入并发送。所选幻灯片会随请求一起发送，因此“这张幻灯片”指的就是所选幻灯片；在幻灯片母版中，助手知道您正在查看哪个基础或版式。示例：

- “为六年级制作一张封面和三张关于分数的幻灯片。”
- “用更短的句子改写这张幻灯片。”
- “做一个逐步显示各个步骤的动画。”
- “找一张水循环的图片，放在右侧。”
- “把整个演示文稿的字体换成更易读的字体。”

输入框中的 **+** 可以附加文件（文本、PDF、图片）、选择技能或 MCP 服务器，以及开启或关闭网络搜索。当请求有多种做法时，助手会在对话中给出选项询问您。

**每项更改都经过检查，并且可以撤销。** 编辑器会检查助手提出的每项更改；未通过的会退回给助手修正。每项已应用的更改都是**一步撤销**（⌘Z）。在**应用前审阅**模式下，您需要先批准每项更改。助手不会保存文件：请您自己用 ⌘S 保存。

**长期说明。** 适用于所有演示文稿的说明位于**设置 → AI 助手**，MCP 服务器和技能也在那里。本次演讲的背景（听众、目标、资料）位于**设置 → 此演示文稿**，保存在 `.eslx` 文件中。

**模型、思考强度和用量。** “发送”旁边有模式、模型和**思考强度**（强度越高，回答越仔细、越慢，用量也越多）。下方显示订阅 5 小时窗口的使用情况。

**对话。** 面板顶部的历史记录可重新打开之前的对话（可搜索）；新对话会开始另一段对话。对话保存在演示文稿中。

**停止。** 助手工作时，**停止**会结束请求；它已应用的更改会保留，可用 ⌘Z 撤销。

## 8. 互动问题

**插入 → 互动问题**会把幻灯片变成实时提问：**单项选择**、**词云**或**开放式回答**。在导出的 HTML 中，您用演讲者密钥解锁问题，听众扫描二维码并用手机作答，结果以条形图、词云或列表显示，并可下载 CSV。

回答会经过一个由**您或您的机构托管**的问题服务器（PHP 和 MySQL，[代码库](https://github.com/mgarlabx/edukors_slides_editor)中有安装指南）。在**设置 → 互动问题**中填写其地址，并使用**测试连接**。没有服务器时，包含问题的演示文稿无法导出为 HTML：导出对话框会显示提示，并提供前往设置的入口（PDF 和 PPTX 仍可导出）。

## 9. 放映和导出

**放映**（⌘↵）从所选幻灯片开始播放演示文稿，只有导航功能，用于排练。放映窗口的控件在中文和印地语界面下显示为英文。

**导出**（⌘E）可生成：

| 格式 | 您得到的内容 |
| --- | --- |
| **HTML**（推荐） | 单个文件，包含图片、字体和动画，可在任何浏览器中打开，离线也可以（只有互动问题需要网络）。 |
| **PDF** | 每张幻灯片一页，为图片形式。 |
| **PPTX** | 可编辑的 PowerPoint 演示文稿：文本、图片和形状成为原生对象（字体、字号、颜色、对齐、链接）；没有对应项的内容（渐变、基础装饰、自由绘图）作为每张幻灯片的背景图片。动画和互动问题不会导出。 |

导出的文件与演示文稿放在同一位置并使用相同名称；如果已存在同名文件，编辑器会先询问是否替换。

**在导出的 HTML 中**，方向键、空格键和 Page Down/Up 用于切换幻灯片。把鼠标移到顶部角落可看到工具：**演讲者面板**（在另一个窗口中打开，显示所有幻灯片并突出当前幻灯片）、**画笔**、**荧光笔**、**文本**、**橡皮擦**、**放大镜**、无限**白板**和**全屏**。底部角落显示幻灯片轨道，悬停时可预览。无论编辑器使用哪种语言，HTML 的控件始终为英文。

## 10. 快捷键

在 Windows 和 Linux 上，⌘ 对应 Ctrl，⌥ 对应 Alt，⇧ 对应 Shift。

| ⌘Z / ⇧⌘Z | 撤销 / 重做 |
| ⌘X / ⌘C / ⌘V | 剪切、复制和粘贴（幻灯片或对象，以最后点击的区域为准） |

| ⌫ | 删除幻灯片或对象 |
